# The deploy kit

!!! info "For operators"

    This page is the deploy kit's own README (`kit/` in the Cerea repository),
    included here at build time so the site and the kit never drift apart. It
    is the runbook: first run, presets, upgrades, backups, the identity
    provider, break-glass and the rest. [Deploying](deploy.md) is the map of
    how the three deployment paths relate; this page is the kit itself.

The README below is served from the same source the kit ships:
`https://github.com/paoloviviani/Cerea/blob/stable/kit/README.md`. One Cerea
release tag, `vX.Y.Z`, is the kit's version too.
